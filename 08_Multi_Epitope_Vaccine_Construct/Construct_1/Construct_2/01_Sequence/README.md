# Vaccine Construct 2 – Sequence

## Project
Design and In Silico Evaluation of a Multi-Epitope Subunit Vaccine Targeting LptE Protein of Multidrug-Resistant *Acinetobacter baumannii*

## Construct
Vaccine Construct 2

## Description
This folder contains the amino acid sequence and sequence-related information for Vaccine Construct 2.

## Sequence
The complete amino acid sequence is provided in the `Construct_2.fasta` file.

## Purpose
The sequence will be used for physicochemical analysis, secondary structure prediction, and tertiary structure prediction.
