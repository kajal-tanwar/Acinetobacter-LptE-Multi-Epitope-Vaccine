# B-Cell Epitope Prediction

This folder contains the linear B-cell epitope prediction results for the LptE protein of *Acinetobacter baumannii* using the IEDB BepiPred 2.0 server.

## Tool Used

- **Tool:** IEDB BepiPred 2.0
- **Website:** https://www.iedb.org/
- **Prediction Type:** Linear B-cell Epitope Prediction

## Files

- **BepiPred_Graph.png** – Graphical representation of predicted B-cell epitopes.
- **B_Cell_Epitopes.xlsx** – Complete B-cell epitope prediction results.
- **B_Cell_Results.md** – Summary and interpretation of the prediction results.
