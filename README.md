# Design and In Silico Evaluation of a Multi-Epitope Subunit Vaccine Targeting LptE Protein of Multidrug-Resistant Acinetobacter baumannii

## Objective
To design and evaluate a multi-epitope subunit vaccine targeting the LptE protein of multidrug-resistant Acinetobacter baumannii using immunoinformatics approaches.

## Workflow
1. Sequence Retrieval
2. Antigenicity Prediction
3. Allergenicity Prediction
4. Epitope Prediction
