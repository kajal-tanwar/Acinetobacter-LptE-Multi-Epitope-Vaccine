# MHC-I Epitope Analysis

## Overview

This folder contains the results of **MHC-I epitope analysis** performed as part of the in silico multi-epitope subunit vaccine design targeting the **LptE protein of multidrug-resistant *Acinetobacter baumannii***.

The analysis was performed to identify potential **MHC-I binding peptides** that may serve as candidate cytotoxic T-lymphocyte (CTL) epitopes for further vaccine design.

## MHC-I Epitope Prediction

MHC-I epitopes were predicted from the selected LptE protein sequence using an MHC-I epitope prediction approach.

The predicted peptides were evaluated based on their MHC-I binding properties and subsequently screened using additional immunoinformatics analyses.

## Immunogenicity Analysis

The predicted MHC-I peptides were evaluated for their predicted immunogenicity using **VaxiJen 3.0**.

For this project, peptides showing **100% predicted immunogenicity** were prioritized according to the selection criterion provided by the project mentor.

Peptides with lower predicted immunogenicity, such as 66%, were retained in the complete results for documentation but were not prioritized for final selection.

## Allergenicity Analysis

The shortlisted MHC-I peptides were evaluated for allergenic potential using **AllerTOP v2.1**.

Peptides predicted as **Non-allergen** were considered suitable for further screening.

## Final Selection Criteria

MHC-I peptides were prioritized for further vaccine design based on the following criteria:

* Favorable MHC-I binding properties
* **100% predicted immunogenicity**
* **Non-allergenic** prediction
* Suitability for subsequent vaccine construct development

## Results

The complete MHC-I epitope analysis, including peptide sequences, immunogenicity results, and allergenicity results, is provided in:

`MHC_I_Epitopes.xlsx`

The Excel file contains both the evaluated peptides and their corresponding screening results.

## Summary

The MHC-I epitope analysis identified candidate peptides from the LptE protein for potential inclusion in the multi-epitope vaccine construct. Peptides satisfying the defined selection criteria were prioritized for subsequent stages of vaccine design.
