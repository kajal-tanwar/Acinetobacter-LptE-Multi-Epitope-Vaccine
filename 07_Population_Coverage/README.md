# 07_Population Coverage

## Overview

This folder contains the population coverage analysis performed for the selected MHC-I and MHC-II epitopes of the multi-epitope vaccine candidate targeting the LptE protein of *Acinetobacter baumannii*.

The analysis was performed using the IEDB Population Coverage tool to estimate the percentage of individuals expected to respond to the selected T-cell epitopes across different geographical populations.

## Folder Structure

* `01_MHCI_Coverage/` – Population coverage analysis of selected MHC-I epitopes.
* `02_MHCII_Coverage/` – Population coverage analysis of selected MHC-II epitopes.

## Analysis Parameters

The analysis was based on the HLA alleles associated with the selected MHC-I and MHC-II epitopes. The IEDB Population Coverage tool was used to estimate:

* Average Population Coverage (%)
* Average Number of Epitope Hits

## Purpose

Population coverage analysis was performed to assess the potential global applicability of the predicted multi-epitope vaccine candidate and to determine whether the selected epitopes are likely to provide broad HLA population coverage.

## Results

The detailed results, tables, and corresponding figures are provided in the respective MHC-I and MHC-II subfolders.
